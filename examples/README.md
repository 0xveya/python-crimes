# python-crimes examples

Run these from the repository root with `uv run python examples/<name>.py`.

- `pipes.py` — `@pipe`, `value @ stage`, and `.with_()`.
- `deferred.py` — `DeferStack`, `@deferred`, `terminate`, and `.q` bubbling.
- `matching.py` — captures, guards, regex, structural patterns, and typed-errs arms.
- `dispatch.py` — a reusable matcher composed using `@`.
